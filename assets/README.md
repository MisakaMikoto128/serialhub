# assets/ —— 图标资产契约 (FR-15 / ADR-18③) 与内置主题源

本目录分两部分: `themes/` 是**代码资产** (内置主题源文件, 随源码提交, 必须存在);
其余是 **icon-designer 的交付物**, 按下表契约命名, build.rs 检测到才嵌入
(CI 三平台**不依赖**图标文件存在 —— 缺文件时运行时回退程序内绘制的圆点图标)。

## 交付物契约 (icon-designer)

| 文件 | 规格 | 用途 |
|---|---|---|
| `master.svg` | 桥+串口母题, 16px 可辨 | 设计主稿 (单一来源, 其他尺寸由此导出) |
| `app.ico` | Windows 多尺寸 16/24/32/48/64/128/256, 须含 PNG 压缩条目 (Vista+ 标准) | exe 内嵌图标 (build.rs + winres, 仅 Windows 目标); 窗口图标取其中最大 PNG 条目解码 |
| `png/serialhub-{16,24,32,48,64,128,256}.png` | RGBA PNG, 透明底 | 各平台备用位图 (窗口图标回退源: `png/serialhub-64.png`) |
| `tray-open.png` | 32×32 RGBA PNG, 运行中·绿 | 托盘三态之一 (hIcon 仅换图, ADR-12 三修口径) |
| `tray-retry.png` | 32×32 RGBA PNG, 重连中·琥珀 | 托盘三态之一 |
| `tray-closed.png` | 32×32 RGBA PNG, 已停止·灰 | 托盘三态之一 |
| `favicon.svg` | 单色可缩放, 任意底可辨 | 网页收藏夹图标 (`GET /favicon.svg`) |

硬性要求:

1. **命名不可改** —— build.rs 按上表逐字匹配; 嵌入是"存在即用", 不存在即回退,
   不阻塞构建。
2. **tray-\*.png 必须 32×32 RGBA** —— tray-icon/tao 的 Icon::from_rgba 吃原始
   RGBA; 其他尺寸会被拒绝并回退圆点。
3. **app.ico 须含 PNG 压缩条目** —— 运行时窗口图标走 "ico 目录 → 最大 PNG 条目
   → 解码" 路径; 纯 BMP 条目不受支持 (回退圆点)。
4. 色彩语义与 UI-3 徽章一致: Open=绿 / Retry=琥珀 / Closed=灰。

> 当前仓库内若有同名占位文件 (圆点临时图), 属于集成联调用, 交付时直接覆盖,
> 勿作为设计基准。

## themes/ —— 内置主题源 (FR-14 主题插件)

`themes/*.css` 每文件 = 一套主题, **只覆盖 `:root` 设计令牌**, 经
`include_str!` 编译进二进制, 首次启动落盘到主题目录 (exe 旁 `themes/` 或
`--themes-dir` 指定)。`example-oreo.css` 文件头即用户自制主题的说明范本。
修改令牌需同步 `ui/index.html` 的 `:root`。

## 设计说明 (icon-designer, 2026-09-13)

### 母题: 桥 + 枢纽

「SerialHub = 串口集线器」→ 一条**绿拱桥**两端落在两只**深灰端口墩**上
(DB9 的抽象), 拱心正下方的**深绿圆点**即枢纽 —— 多路汇于一点。
桥 = 连接 (打开串口), 墩 = 端口, 点 = 枢纽; 三个语义一层讲完。
形状共 5 个 (瓷片底 / 左墩 / 右墩 / 桥拱 / 枢纽点), 全部几何绘制。

### 配色

| 角色 | 色 | 来源 |
|---|---|---|
| 桥拱渐变 | `#2f9e5f → #1f7a47` (上→下) | 品牌绿双绿 |
| 端口墩 | `#37424a` | 中性深灰, 与 UI `--ink` 同族 |
| 瓷片底 | `#f8fbf9 → #e2eae5` + 描边 `#c9d4cd` | 浅色工业风 `--panel` 系 |
| 枢纽点 | `#1f7a47` | 品牌深绿 |
| 托盘状态角标 | 绿 `#2f9e5f` / 琥珀 `#e5a23c` / 灰 `#9aa4a0` | Open/Retry/Closed, 与 UI-3 徽章语义一致 (琥珀/灰为暗底托盘提亮档) |

### 为什么 16px 可辨

- **先画 32px 网格** (viewBox 0 0 32), 所有坐标落在半格上, 再放大出图;
- 桥拱描边 3.8/32 (16px 下 ≈1.9px), 两墩 8×7.5 (≈4px 实心块), 是最小的"可读单元",
  无细线、无文字、无多级细节;
- 早期版本曾把白色枢纽珠嵌在拱顶 —— 16px 下拱被切断, 目检否决;
  定稿改为**连续拱 + 拱心下实心点**, 拱在任何尺寸不断线;
- 拱脚垂直落在墩顶 (塞进端口), 16px 下两墩与拱的相对关系仍成立;
- 已逐档导出 16/24/32/48/64 目检 (浅底/深底双排放大图), 16px 下
  「绿拱 + 双墩 + 状态角标」均可辨; 光栅化用 64× 超采样 + LANCZOS 缩小,
  PNG 由同一几何参数程序化生成, 与 SVG 像素级同源。
