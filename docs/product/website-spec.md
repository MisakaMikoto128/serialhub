# SerialHub 发布官网 规格 (WEB v1, 2026-09-14)

> 来源: 用户 2026-09-14 下达 —— "做一个发布网站方便别人下载; 域名麻烦, 安装包用国内外免费托管,
> 网站也用免费托管; 可模仿 qingjian.app 但别抄袭"。编号 WEB-x, 与产品 spec.md 的 FR-x 并行;
> 网站是独立静态产物 (website/), **不进二进制**。托管选型见 ADR-23, 小组编制见 org.md 7xx 排。

## 1. 目标与用户

- 目标: 访客 30 秒内明白 SerialHub 是什么; 1 分钟内拿到对应平台的安装包 (或到得了 GitHub 仓库)。
- 用户: ① 首次访客 (搜串口工具的开发者/硬件工程师); ② 回访老用户 (找新版本/更新日志)。
- 参考站 qingjian.app 踏勘结论 (2026-09-14): 单页站, 结构 = 导航 → hero (标语+特性标签+双按钮)
  → 特性网格 → 理念区 → 交互演示 → 反面清单 → 页脚; 下载走站内独立页; 全中文。
  **只借鉴信息架构**, 其文案/视觉/代码一律不抄 (ADR-23④)。

## 2. 站点结构 (WEB-1 单页式, 锚点导航)

| 区块 | 内容要点 | 对应 |
|---|---|---|
| 导航 | 站名 + 锚点: 特性 / 截图 / 下载 / 快速开始 / 更新日志 | WEB-1 |
| Hero | 一句定位 + 双按钮 (下载 / GitHub 仓库) + 平台标签 (Windows/Linux/macOS) | |
| 特性网格 | 4~6 条: 多桥并存 / 热拔插自动重连 / 统计可视化 / 主题插件 (措辞对齐手册) | WEB-3 |
| 截图区 | 真实管理台截图 (docs/images 现有素材精修), 不放概念图 | WEB-4 |
| 下载区 | 版本号+日期 / 三平台包 / 双通道按钮 (GitHub Releases + 国内网盘) / SHA256 / 系统要求 | WEB-2 |
| 快速开始 | 3 步: 下载解压 → 运行 → 浏览器开管理台 (与手册一致) | |

| 页脚 | Apache-2.0 / 仓库 / 手册 / 安全提示 (链 SECURITY.md) | WEB-8 |

## 3. 需求条目

- **WEB-1 单页官网**: 纯静态零依赖 (HTML+CSS+原生 JS, 单目录 website/, 不引框架不做构建);
  源码入库; release.yml 已自动化安装包上传, CI 另加 Pages 发布 job (发布动作归部署测试组)。
- **WEB-2 下载双通道**: 国际 = GitHub Releases (权威源, 已自动化, v1.2.0 起八版在架); 国内 =
  Cloudflare Pages 镜像站直挂安装包 (与 WEB-6 同一 Google 登录账号, 单文件上限量级 25MB,
  超限用 R2 免费档或回退 Releases 直链; 蓝奏云候补)。站点并列按钮并注明适用网络; 每包公布
  **SHA256** (发布工程组自 CI 产物核算); 版本/日期/链接/SHA 集中为页面内单一数据块, 逐版替换。
- **WEB-3 内容原创规范**: 文案全原创, 禁复制参考站文案/源码/图片; 术语对齐 UI-0 自明性词表
  (说"串口/网页/网址/下载/桥", 禁实现词"WS/监听/换绑/契约"); 与 README/手册用词一致, 不发明新词。
- **WEB-4 视觉原创**: 延续产品自己的设计语言 (设计令牌思路 + FR-15 桥/端口母题图标资产复用);
  配色不仿参考站; 可选 win95 主题彩蛋 (产品自有的梗) 但不喧宾夺主。
- **WEB-5 兼容与体验**: 360px~1440px 不破版; 无追踪脚本/Cookie/外部字体 CDN (隐私零负担);
  全站链接零死链 (含外链可达)。
- **WEB-6 分阶段部署**: 首版 = GitHub Pages 主站 (Pages 已开通, CI 加 deploy job 即上线;
  项目站按仓库名隔离, 与账号下其他项目互不冲突, 平台默认子域, 未来可一键 CNAME);
  P1 增强 = 国内镜像 Cloudflare Pages (Continue with Google 单账号, 同时直挂安装包, 见 WEB-2;
  EdgeOne Pages 备选 —— 微信扫码, CF 国内实测不快时启用), 可达性以 708 实测为准。
- **WEB-7 SEO 基础**: title/description/og:image/favicon 齐全; sitemap 列 P2。
- **WEB-8 非目标 (首版不做)**: 论坛/评论/账号体系/访问统计埋点/自动更新器 (B 系列以后)/多语言 (P2)。

## 4. 验收口径

1. **双通道真机下载**: 从 GitHub Releases 与国内直链各下载一次安装包并核对 SHA256
   (国内通道未上线期间按 Releases 单通道验收, 上线后补验国内侧);
2. **国内外可达性**: 主站 + 镜像站两条 URL, 有/无代理各实测一轮 (截图留档 reports/web-deploy.md);
3. **多分辨率不破版**: 360/720/1440 截图; 断链检查 0 死链 (含外链可达);
4. **UX 走查**: 新手视角 "弄清这是什么并下载安装包" 任务无未关闭 P0/P1;
5. **原创性核对**: 与 qingjian.app 逐区块对照, 无文案/视觉/代码相似项。
