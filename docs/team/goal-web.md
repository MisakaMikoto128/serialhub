# 发布网站角色常驻指令 (goal-web, 2026-09-14)

> 派工方式: 贴本文件**对应小组节** + docs/product/website-spec.md 全文 + 本 Sprint 范围 + 仓库路径
> (11 席共用一个文件, 全文粘贴冗余, 故只贴所需节)。汇报一律写 docs/team/reports/web-<组别>.md
> (不只写在回话里); 不许改 src/ ui/ tests/; 原创红线 (ADR-23④) 逐条遵守; 发现规格问题在报告
> 末尾列 `SPEC-QUESTION:` 交架构师裁决。参考站 qingjian.app 仅限看页面结构, 禁止照抄其源码/文案/图片。

## 703 文案组

- 产出 reports/web-copy.md 文案表 (逐区块给出, 架构师审定后由 706 落页):
  定位语 ≤20 字 / hero 副标 1-2 句 / 特性 4-6 条 (每条 ≤16 字标题 + 一句白话) /
  快速开始 3 步 / 更新日志摘要 (自 CHANGELOG.md 提炼, 不堆砌) / 页脚免责与安全提示。
- 术语对齐 UI-0: 只说用户可感知的事 (串口/网页/网址/下载/桥), 禁实现词 (WS/监听/换绑/契约);
  与 README、手册用词一致, 不发明新词。

## 704 UI 组

- 产出 reports/web-ui.md: 设计令牌表 (色板/字阶/间距/圆角) + 区块布局说明 (桌面/移动两档栅格)
  + 断点 (360/720/1440)。视觉延续产品设计令牌思路, 工业风为主; 不仿参考站配色。

## 702 美术组

- 素材加工入 website/assets/: docs/images/ 现有截图统一裁切尺寸并精修 (不加虚构内容);
  og 图 1200×630 一张; favicon 复用 FR-15 既有资产。禁止新画吉祥物/概念图 (P2 再议)。

## 706 功能开发组

- 实现 website/index.html (+assets/), 纯静态零依赖零构建; 锚点导航; 下载区版本/日期/SHA256/链接
  集中为页面顶部一个数据块 (便于发布工程逐版替换); 移动端 360px 起; 交付前自跑断链检查。
- 不引入 npm/框架/外部 CDN; 不改 src/ ui/; CI 的 Pages 发布 job 由架构师加, 发布动作归 708。

## 707 功能测试组

- reports/web-qa.md: 链接矩阵全过 (含 Releases/网盘外链可达性) / 内容核对 (版本号/SHA256 与
  release.yml 产物一致) / 360-720-1440 三档截图 / HTML 基本校验。对 website/ 本地伺服实测。

## 708 部署测试组

- 双托管发布 (GitHub Pages + 镜像站), 每站记录: 发布方式/URL/国内外实测时间与网络环境 (截图);
  回滚说明 (Pages 回滚 = re-run 旧 commit, 镜像站等价操作)。产出 reports/web-deploy.md。

## 709 发布工程组

- 自 release.yml 产物核算三平台 SHA256; 上传安装包至蓝奏云 (国内通道), 记录直链与平台规则;
  回填站点数据块 (版本/日期/链接/SHA256)。产出 reports/web-release.md。

## 710 安全与合规组

- reports/web-compliance.md 清单: Apache-2.0 声明 + LICENSE/NOTICE 链接; 安全提示对齐
  SECURITY.md (v1.x 无 TLS, 勿暴露不可信网络); 隐私声明 (站点无 Cookie/无统计/无第三方脚本);
  国内网盘标注"官方直传镜像"防钓鱼口径。

## 705 用户体验组

- 新手视角走查: 只给站点 URL, 任务 = "弄清这是什么并下载安装包、完成校验"; 记录卡点
  P0/P1/P2 + 截图, 产出 reports/web-ux.md。不直接改任何文件。
