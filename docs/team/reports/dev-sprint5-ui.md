## 1. 实现 (ADR-15② 三块全落地)

1. **retry 态错误行**: 徽章「重连中」下方错误行改琥珀变体, 明示「串口已断开，正在自动重连 (第 n 次)…」(n=每轮轮询实时跟随 `retries`); `lastError` 有内容时以次级灰字 (--muted 11px) 展示后端原话, 不翻译不改写。`retries` 字段缺失/为 0 时不伪造次数 (DEF-2 同款诚实降级, 只显示「…正在自动重连…」)。
2. **恢复横幅**: 每轮轮询做状态判定 —— 该桥自上次打开成功以来出现过 retry (允许 retry→连接中→运行中跨两轮), 归「运行中」的瞬间该卡片顶部出现一次性绿色横幅「串口已恢复」, 3s 自动消失; 页内元素 (`role=status`, 不弹窗不抢焦点)。恢复时刻同步进错误行位置: 绿色变体「串口已恢复 · HH:MM:SS」, 窗口结束后回归常规逻辑 (lastError 或隐藏)。判定态 (wasRetry/recoveries/定时器) 随桥删除一并清理。
3. **断档不伪装**: 火花线原逻辑照常每秒采样 (retry 期间速率自然为 0, 断档以零段真实呈现, 零改动); 流程图线段 retry 态加 `.retrying`: 半透明 (≤0.35) + `wireGap` 断续闪动 (1.2s, steps 三档 0.35/0.215/0.08), 恢复即移除。速率数字 0 B/s 照实显示。

实现要点: 卡片仍为原位更新 (500ms 轮询不重绘), 新增三态错误行状态机 (retry 琥珀 / 恢复窗口绿 / 常规上次出错红) 集中在 `updateCard` 一处; 横幅定时器到期即刻回归常规错误行, 不等下一轮轮询。

## 4. 契约使用与注记

- `retries`: u32, 按派工契约消费; 缺失/0 时不显示次数 (防契约回退, 同 DEF-2 思路)。次数语义按 ADR-15①「当次会话内重试计数」, UI 只透传不解释。
- 恢复判定在前端按轮询相位推断 (retry 史→open), 不要求后端新增事件; 若后端日后提供恢复时刻戳, 「串口已恢复 · HH:MM:SS」可换源, 一处改动。
- 抽屉统计页错误行维持「上次出错」原样 (本轮范围仅卡片/列表页); 若 UX 走查要求同款白话, 改动小, 留波2。
