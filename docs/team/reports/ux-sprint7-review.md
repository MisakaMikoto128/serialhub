## 发现 (P1 = 难受, P2 = 锦上添花; 均未改代码)

### P1-1 主题下拉默认态与实际主题不符 (截图 02)
- **现象**: localStorage 无 `sh_theme` (新浏览器 / 改管理台网址跳新 origin 后必现) 时,
  页面实际是内置**浅色**, 但打开「设置」→ 主题下拉显示**「深色」**。
- **根因**: `fillThemeSelect()` 只在 `themeNow` 命中列表时才 `sel.value = themeNow`;
  `themeNow = null` 时下拉留在列表第一项 (真后端 `/api/themes` 返回序 dark 在前)。
  mock 阶段列表序不同, 没暴露。与 dev-sprint7-ui §3.7 (主题记忆不跨端口) 叠加:
  用户跳到新网址打开设置, 第一眼看到的就是错的主题。
- **建议**: `fillThemeSelect` 末尾无命中时回落 `sel.value = themeNow || "light"`
  (或以 `themeNow ?? "light"` 兜底参与匹配)。

### P1-2 内置第三主题在下拉里露英文 ID「example-oreo」 (截图 02/08)
- **现象**: 主题下拉三项 = 浅色 / 深色 / **example-oreo** —— 两项中文一项英文,
  破坏"同一个软件"感, 也违背 UI-0 (用户不该猜 ID)。
- **根因**: `THEME_LABEL = { light, dark, oreo }` 的键是 `oreo`,
  真后端内置文件名/`/api/themes` 返回的是 `example-oreo`, 映射落空显示原名。
- **建议**: `THEME_LABEL` 补 `example-oreo: "示例·奥利奥"` (或后端 themes API 加显示名字段;
  若怕第三方主题名不可枚举, 可约定 `label` 字段优先)。

### P2-1 页头按钮 34/28 混排同排 (截图 01/09)
- **现象**: 打开面板/设置 34px 与 复制/退出程序 28px 同排 (任务钦定、QA 两档皆合规),
  肉眼可见"两代按钮"; 720 窄屏 flex 换行后 打开面板 与 设置 还会被拆到两行 (截图 14)。
- **建议**: 页头统一 28 紧凑档 (dev 报告 §1.3 预留的两行档位改法) —— 复制/退出程序是原住民,
  新钮就高不就低反而突兀; 或全页头 34 并让换行时新钮同排。

### P2-2 统计页签摘要行校验位显示裸「--」 (截图 07/11)
- **现象**: `串口 COM1 · 115200 · -- · 流控 无` —— 中间 "--" 无标签, 新手不知是校验位
  (UI-0: 不看文档猜不出)。旁证: 新建桥/桥设置里同字段写作「N 无」。
- **建议**: 显示「校验 无」或与下拉一致用「N 无」。

### P2-3 「📋 复制」按钮 emoji 与全站纯文字按钮不一致 (截图 05/10)
- **现象**: 抽屉-设置页签「命令行写法」组内 `📋 复制`; 全站其余复制钮 (页头/卡片/数据网址) 均无图标。
- **建议**: 去掉 emoji, 或全站统一给复制钮加同款图标 (工作量取小者)。

### P2-4 串口下拉项端口名重复 (截图 03)
- **现象**: `COM8 — USB-SERIAL CH340 (COM8)` —— 描述自带的 "(COM8)" 与前缀重复
  (COM1/COM2 无描述故不显)。本轮未触碰 COM8, 仅观察下拉文案。
- **建议**: 渲染时剥掉描述尾部的 `(COMxx)` 再拼。

## 核对无误项 (任务 1-5 对应结论)

1. **UI-1 尺度**: 令牌 34/28、8px 圆角、13px 全站稳; 实测页头 34/34/28 (见 P2-1, 唯一混排在页头)。
   卡片内 启动/设置/删除、弹窗 取消/应用、抽屉表单节奏整齐, 未再见第三种高度。
2. **层级**: 主 (蓝实底)/次 (描边)/危险 (红描边) 三档分量全区域一致; 危险 armed 态两主题实测
   `--err` 底 + `--err-bg` 字 (浅 ≈4.6:1, 深 ≈4.6:1), Sprint7 波2 令牌化修复生效;
   两段确认预告文案大白话, 3s 自动复原正常。
3. **深色可读性**: 卡片/徽章四态/流程图节点/火花线 (rx 绿 tx 蓝 随主题)/终端 (term-bg 上正文清晰)/
   开关/琥珀运行中横幅逐区域扫过, 无对比度不足或突兀色; 无刷新换肤 + 重载防闪白正常。
4. **信息密度**: 新钮都在页头不进卡片, 卡片密度未变; 720 下卡片按钮/统计行折行有序、
   网址截断有省略号, 双主题 1280/720 均无横向滚动。
5. **新手视角 (UI-0)**: 设置弹窗全部词 (主题/浅色/深色/管理台网址/取消/应用) + hint + 悬浮题
   均说人话, 0 实现词; 「打开面板」浏览器实测 window.open 新标签直达;
   「应用」值未变时禁用正确。
