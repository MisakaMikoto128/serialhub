## 1. 行为 (FR-17)

1. **预填**: 打开「新建一座桥」表单时, 网址端口先留空, 异步取 `/api/fleet`, 以管理台端口
   (`location.port`) 为基准从 **+1 起向上探测**, 跳过 fleet 里各桥 `listen` 的端口
   (正则 `/:(\d+)$/` 提取, 兼容 IPv6 形态), 预填第一个空闲的 → `127.0.0.1:<端口>`。
   例: 管理台 8080、已有桥 8081/8083/8090 → 预填 **8082** (实测)。
2. **每次打开都重算**: 桥列表变了预填跟着变。实测: 预填 8082 → 创建并启动 (fleet 新增 8082)
   → 再开表单预填 **8084** (实测, 跳过 8081/8082/8083/8090)。
3. **用户仍可手改**: 预填写入后不锁字段; 一旦用户在本次表单里改过 (`input` 事件置 touched),
   异步预填绝不覆盖手输值 (竞态守卫 `npPrefillSeq` 兼顾快速开关表单只认最近一次打开)。
4. **失败不阻塞**: `/api/fleet` 拿不到 (或 65535 耗尽, 理论路径) → 字段留空 + 提示行
   **「填一个空闲端口」** (实测 500 路径); 表单照常可开、可提交, 提交校验沿用 `validateListen`。
   恢复后 (fleet-fail 复位) 再开表单预填恢复正常 (实测 8084)。
5. **UI-0 提示**: 预填成功时字段下方一行 **「已为你选好一个空闲端口, 可修改」**, 仅预填态显示
   (手改即收起; 端口字段报红字错时也让位收起); 无实现词。
6. 防御: `location.port` 为空 (80/443 直连) 时按协议取 80/443 作基准 —— 常规部署管理台带端口,
   该分支只是不炸。

## 2. 边界与已知限制 (按任务钦定范围)

- **纯前端推算**: 只看 fleet 数据 + location.port, 不实际探测 OS 端口占用 —— 被非 SerialHub
  程序占用的端口不感知 (任务明示「fleet 数据 + location.port, 无需新端点」); 真撞占用时建桥会
  走既有建桥报错路径, 用户改一个端口即可, 不新增处理。
- 预填异步到达 (打开后几十 ms 内), 打开瞬间字段短暂留空; 用户极快手输不会被覆盖。

# 批次 A · A2 建桥表单记忆上次参数 (dev-ui 301 追加)

- 日期: 2026-09-14 · 变更文件: **仅 `ui/index.html`** (npRestoreHint 元素 / readLastBridge+saveLastBridge
  / openNew 回填 / createBridge 成功写入四处; 未 commit) · 依据: ADR-22② · backlog「批次 A」A2 · UI-0
- 自验: fr17 同族 mock 管理台 (127.0.0.2:8080, 已有桥 8081) + Playwright **22 断言全过**;
  全程 mock, 未碰真实串口; 脚本在 %TEMP%\a2-mock.mjs / a2-test.mjs (不入库); 未碰 src/tests

## 1. 行为 (ADR-22②)

1. **记忆**: 建桥成功 (`POST /api/fleet` 返回 ok) 时写入 localStorage `sh_lastbridge`
   {port, baud, dataBits, parity, stopBits, flow}; 失败不动历史。浏览器侧用户习惯, 不进 fleet.json。
2. **回填**: 打开「新建一座桥」时六字段回填上次值; **串口只选回扫描列表里仍存在的口** —— 借
   `scanInto→fillPortSelect` 既有的 cur 保持机制 (预填上次值后扫描, 不在列表就不选回, 落回列表默认,
   用户自己选), 不新增端点; 波特率/数据位/校验/停止位/流控直接回填。
3. **优先级**: 网址端口仍走 FR-17 空闲递增 (实测 8082→8083→8084 跳过已用), 与记忆互不覆盖;
   其余字段 = 上次值; 无历史 (首次使用/清了 localStorage) 维持现状默认 115200/8/N/2/none。
4. **UI-0 提示**: 有回填时流控行下一行「已按上次使用的参数填好, 可修改」(新元素 `#npRestoreHint`,
   复用 `.send-hint` 样式), 仅回填发生时显示; 与 FR-17 的端口提示并存不冲突 (各占一行)。
5. **约束**: 设置抽屉编辑表单 (cf*) 不参与记忆 —— 实测回显该桥自身值 (COM1/9600/7/E/1), 逻辑零改动。
6. 防御: 记录损坏/字段非法时逐字段按无记忆处理 (下拉只认合法枚举, 波特率校验 110~2000000 区间),
   不会把下拉选成空白; localStorage 不可用 (隐私模式) 时静默放弃记忆, 不影响建桥。

## 3. 边界与留给 QA

- 串口"留空"的实态: 列表里没有上次口时**不强行选回**, 落到扫描列表默认首项 (与无历史行为一致);
  若希望显式空占位需改 fillPortSelect, 超出本条范围。
- 记忆按"最后一次成功建桥"为准 (不做多槽位); 换浏览器/清站点数据即失忆, 属预期。
- 真壳 (wry webview) 的 localStorage 持久性归 QA 波1 复验; 像素审计无新控件形态 (仅一行提示复用)。
