## 五、问题分级清单

### P0 (阻断任务)

无。

### P1 (严重阻碍)

无。

### P2 (打磨项)

1. **360px 顶部导航「更新日志」初始不可见**
   - 截图: `10-firstscreen-mobile.png`; 复现: 360px 宽打开首页, 导航条只见「特性/截图/下载/快速开始」。
   - 实测: 「更新日志」位于 x=360 (视口右缘之外), 藏在 `overflow-x:auto` 的横滑导航条内 (scrollWidth 292 vs clientWidth 220), 且无渐隐边/箭头等可滑动提示, 新手不知其存在。
   - 影响: 不阻断下载任务 (日志区随页面滚动仍可达), 但伤及 spec §1 用户② (回访老用户找新版本) 的移动端体验。
2. **导航链接触达偏小**
   - 导航链接热区约 28×19px, 低于移动端 44px 建议值 (WCAG 2.5.8 最小 24px 勉强达标)。复现: 360px 下查看导航条 (截图 `10`)。
3. **无平台自动识别/推荐**
   - 三平台卡权重均等, 新手需自行判断 (各卡「适合…」说明与系统要求行有缓解)。复现: 打开下载区 (截图 `02`)。加分项方向: 按 UA 高亮"当前系统"。
4. **GitHub Releases 页发布说明过薄 (站外信任短板)**
   - 截图: `06-releases-page.png`。Releases 正文仅一行 "SerialHub v2.0.2", 与站内丰富的版本摘要不对等; 从站外直入 Releases 的访客获得的信任信息少于站内。属发布工程侧配合项, 非站点页面缺陷。

## 六、新手四问

- **是什么?** 一个把串口设备变成 WebSocket 字节管道的桥接工具, 网页和脚本直接读写原始字节, 多座桥一个管理台管。
- **给谁用?** 需要在网页里收发串口数据的开发者与硬件爱好者 (调试、联机、给页面接硬件)。
- **怎么装?** 下载对应平台压缩包 → 解压 → Windows 双击 serialhub.exe (Linux/macOS 终端 `./serialhub`) → 浏览器开 `http://127.0.0.1:8080` 新建桥。三步卡+可复制命令, 无需文档也能装。
- **可信吗?** 可信。Apache-2.0 开源、版本/日期与 GitHub 实时一致、SHA256 公布且实测吻合、校验方法手把手给、安全边界 (未加密无鉴权) 主动声明、无追踪无外部请求。
